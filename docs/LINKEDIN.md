Can my code act on the model's answer?

I ran the same six fake order tickets through a Cursor Cloud Agent and through TypeSafe Jev (System One, jev-1.13.0). The LLM wrote prose. Jev returned `allow`, `escalate_to_human`, or `deny`, plus probabilities. Python hard rules still got the last word.

On the concentration ticket both models said deny. The gate escalated anyway. One name would have been 32% of the book, and the cap I wrote in code is 15%.

This is not stock picking. Not a broker. Not a return forecast.
